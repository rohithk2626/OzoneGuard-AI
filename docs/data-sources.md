# Data Sources

This page covers the NOW (Location) sources. The FUTURE (Predictions) sources — CAMS via Open-Meteo, archived NWP forecasts, and every dataset investigated — are in `prediction-data-sources.md`.

## NASA OMI/Aura OMTO3G
- Dataset: OMTO3G V004
- Variable: ColumnAmountO3
- Resolution: 0.25° × 0.25° daily Level-2G grid
- Access: NASA Earthdata / GES DISC
