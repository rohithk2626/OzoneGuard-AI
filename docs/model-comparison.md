## Models

* **xgboost**: XGBoost, trained 2026-10-07; direct multi-horizon (lead_h feature), 1-24 h, hourly.
* **lstm**: LSTM, trained 2026-10-26; encoder-decoder LSTM: 48 h history -> 24 hourly outputs in one pass.

## How to switch

* Per request: `GET /api/v1/predictions/24h?lat=..&lon=..&model=lstm` (or `model=xgboost`).
* Server default: set `OZONEGUARD_MODEL=lstm` in `.env` (default is `xgboost`).
* Both side by side: `GET /api/v1/predictions/models`.
