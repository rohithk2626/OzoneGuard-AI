About OzoneGuard AI

Final-year B.Tech CSE-AIML project.

Introduction

An AI-assisted platform for monitoring local ozone and UV conditions in India.

Problem statement

The public lacks accessible, location-specific UV risk information based on ozone and weather data.

Objectives

Present current conditions, forecast UV risk, analyse historical trends and give safety guidance.

Proposed solution

A web dashboard backed by a FastAPI service and an ML model trained on satellite and weather data.

AI/ML methodology

Feature engineering on ozone, cloud, weather and solar variables; regression or time-series models; evaluation with held-out data.

Data sources

Planned: satellite ozone products (e.g. NASA), weather and UV APIs. Currently the UI uses mock data.

Technologies

HTML5, CSS3, JavaScript, Chart.js, Leaflet.js, OpenStreetMap, Lucide; future Python, FastAPI, scikit-learn/TensorFlow, database.

Architecture

Data sources → ingestion/processing → ML model → FastAPI REST → this frontend (js/api.js).
